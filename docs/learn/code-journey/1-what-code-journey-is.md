# Code Journey: what it is and what it offers

A plain-language guide for revision. No code, just the idea and the features.

---

## The one-line version

Code Journey is a free map of tech careers. You pick a job, and it shows you the skills you need, in the order to learn them, with the best free places to learn each one.

## The problem it solves

Many people who want a tech job do not fail for lack of courses. They fail because they do not know **what to learn next, and why**. There is plenty of free material online, but nothing puts it in order, and job adverts list 20 tools without saying which matter first.

Code Journey answers one question for every tech role:

> "To become a ___, what do I learn, in what order, and where do I learn each thing?"

## How it looks: a metro map

The whole site is drawn like a city metro map.

| On the map | What it means |
|---|---|
| A **line** | A field of tech, such as Web, Mobile, Data, AI, Cloud and DevOps, Quality, Security |
| A **destination** | A job, such as Frontend Engineer or Data Analyst (26 of them) |
| A **station** | One skill on the way, such as Git or SQL (99 of them) |
| A **route** | The stages from start to finish for one job |

A route has four stages: **Foundations, Core, Job-ready and Senior**. Every stage has a project to build and a "you're done when" check, so you know when to move on.

## What the site does

Code Journey does not sell courses and does not teach. It curates. Every skill points to the official documentation first, then to the best free material.

### For everyone, no account needed

- **Map and roles.** Browse the metro map, or open any of the 26 roles to see its route, a typical day, the tools, the interview process and how AI is changing the job.
- **Skill pages.** Each skill has a one-minute explanation, a checklist of what to learn, and hand-picked resources marked free, freemium or paid, with a "last checked" date.
- **Compass.** An 8-question quiz that suggests roles that suit you, and says why ("Because you like finding answers in data").
- **Compare.** Put any two roles side by side: shared skills, time to become job-ready, pay and interviews.
- **Pay by role.** Salaries for India and the US. Every figure links to its public source and date. Nothing is guessed.
- **Job post checker.** Paste a job advert. It lists the skills the advert asks for, which of them the site covers, and the order to learn them. It runs in your browser, and the text is never uploaded.
- **Glossary, blog, FAQ.** Plain-English definitions, short guides and answers to common questions.
- **Contact form.** Send a question, suggestion or bug report to the team.

### For signed-in users (free account)

- **My Path.** Choose a destination, then mark each skill as To do, Learning or Done.
- **Progress view.** Your percentage, your current stage, the next few skills, and roughly how many hours are left.
- **Milestones and celebrations.** A marker for your first skill, halfway, each finished stage and the whole route. Finishing a stage shows a small celebration.
- **Weekly streak.** The number of weeks in a row you have learned something. One busy day keeps it alive.
- **Saved resources.** Bookmark any link to come back to it.
- **Helpful votes and suggestions.** Say whether a resource helped, or suggest a better one.
- **Projects.** Add a link to the project you built for each stage.
- **Public path page.** An optional page, with a handle you choose, that shows your route and progress. Off by default.
- **Weekly progress email.** An optional email once a week with what you finished and what is next. One click to stop it.
- **Themes.** Four colour themes, each in light and dark, saved to your account.

### The AI assistant: CJ AI

CJ AI is a chat helper on every page. It answers questions about tech careers, and it answers only from Code Journey's own pages. Every answer shows numbered sources you can open. If the site does not cover a question, it says so instead of guessing. Signed-in users get a limit of 40 questions a day.

Example questions: "What should I learn after SQL?" or "What does a data engineer do each day?"

### Works like an app

- You can install Code Journey on your phone or computer, with its own icon.
- Pages you have already opened still work offline.
- Private pages, such as My Path, are never saved on a shared device.

## Principles behind it

- **Free to read.** No account is needed to use the map.
- **Official first.** Official documentation is always listed before anything else.
- **Every number has a source.** Pay figures and dates come with a link. Nothing is invented.
- **Privacy by default.** No ads, no selling data, email is opt-in, and the job checker never uploads your text.
- **We curate, we don't sell.** The site has no courses to push, so its advice is about what is best for you.

## What it deliberately does not do

- It does not sell or host courses.
- It does not issue certificates.
- It does not place people in jobs.
- It does not guess salaries or statistics.
