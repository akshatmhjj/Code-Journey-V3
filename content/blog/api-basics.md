## The core idea

An API connects your app to a server. You request data, it responds. That’s the foundation of modern apps.

## How it works

Every request includes a URL and method. The server processes it and sends back data, usually JSON. This pattern is everywhere.

## Why it matters

Without APIs, apps can’t fetch data, authenticate users, or interact with services. Understanding them moves you beyond static projects.
